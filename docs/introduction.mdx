## What is AuditGuard Community?

**AuditGuard Community** is the open community hub where security professionals contribute, share, and maintain skills, scripts, and compliance workflows.

**AuditGuard** is the core engine that runs skills and produces structured audit outputs. **AuditGuard Community** is where those skills live, grow, and get peer-reviewed. Anyone can contribute a skill, report an issue, or propose improvements. The goal is a shared, high-quality library that covers every phase of a security engagement: scoping and recon through exploitation, scoring, and reporting.

## What's in the Community Hub?

| Resource | Description |
|---|---|
| **Skills** | Reusable, self-contained methodology units for pentesting, bug bounty, compliance, and reporting |
| **Scripts** | Automation scripts that support skill execution: scanners, payload generators, report parsers |
| **Contexts** | Engagement-specific knowledge bases for web app pentest, cloud audit, mobile pentest, and more |

## The problem with AI agents and security work

Ask an agent to hunt for IDOR bugs. It will improvise. It misses verb inconsistency checks, skips GraphQL object exposure, and never tests parameter pollution. You re-prompt five times, spend 3x the tokens, and still get an incomplete result.

The agent is not dumb. It lacks a methodology.

## How skills fix this

A skill is a battle-tested methodology file your agent reads before starting a task. It covers every test case, every bypass technique, every output format a practitioner would use. The agent stops improvising and starts executing.

| | Without skill | With skill |
|--|--------------|------------|
| Output quality | Inconsistent | Structured and complete |
| Turns to finish | 3 to 5 | 1 |
| Methodology coverage | Partial | Full |
| Report format | Whatever the agent guesses | Triage-ready, platform-specific |

Skills are installed in one command:

```bash
auditguard-skills add bugbounty-reporter
```

No account. No configuration. The CLI detects your installed agents automatically.

## What is a script?

A script is a standalone automation file that performs a specific audit or compliance task. Unlike skills, scripts are not tied to a workflow. They can be run independently, scheduled, or integrated into external pipelines.

## When to use a script vs a skill

| | Script | Skill |
|---|---|---|
| **Standalone execution** | Yes | No |
| **Part of a workflow** | No | Yes |
| **Scheduled independently** | Yes | Via workflow |
| **Shareable** | Yes | Yes |

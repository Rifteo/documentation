## Template

Use this as a base for any new script you want to contribute.

```yaml
name: your-script-name
description: What this script checks or does
author: your-name
version: 1.0.0
tags:
  - compliance
  - example

run:
  command: |
    # Your script logic here
    echo "Running audit check..."
```

## Fields

| Field | Required | Description |
|---|---|---|
| `name` | Yes | Unique identifier for the script |
| `description` | Yes | Short summary of what the script does |
| `author` | Yes | Your name or GitHub handle |
| `version` | Yes | Semantic version (start at `1.0.0`) |
| `tags` | No | Keywords to help users find the script |
| `run.command` | Yes | The shell command or script to execute |

## Submitting your script

Once ready, open a pull request following the [contribution guide](/docs/contributing).

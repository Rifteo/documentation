## Skills CLI

No configuration file required. The CLI auto-detects installed agents on your machine.

To target a specific agent:

```bash
auditguard-skills add finding-writer --agent claude-code
auditguard-skills add finding-writer --agent gemini-cli
```

To install globally instead of project-level:

```bash
auditguard-skills add finding-writer --global
```

## Context MCP server

### Environment variables

| Variable | Description | Default |
|----------|-------------|---------|
| `AUDITGUARD_CONTEXTS_PATH` | Path to a local contexts repo clone | GitHub API (remote) |
| `AUDITGUARD_LOG_LEVEL` | Log verbosity: `DEBUG`, `INFO`, `WARNING`, `ERROR` | `INFO` |
| `AUDITGUARD_LOG_FILE` | Path to write logs to a file | stderr only |

### Use a local contexts clone

Point the server at a local clone instead of fetching from GitHub:

```bash
AUDITGUARD_CONTEXTS_PATH=/path/to/contexts auditguard-context-mcp
```

Or set it in your agent's MCP config:

```json
{
 "command": "auditguard-context-mcp",
 "args": [],
 "env": {
  "AUDITGUARD_CONTEXTS_PATH": "/path/to/contexts"
 }
}
```

### Bug bounty credentials

Credentials are stored in `~/.auditguard/credentials.json` and managed via the CLI:

```bash
auditguard-context auth hackerone
auditguard-context auth --list
auditguard-context auth --remove hackerone
```

See [Commands](/usage/commands) for the full reference.
